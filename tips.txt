---

## ✅ Nettoyer automatiquement les matricules dupliqués dans MySQL

---

### 🎯 Objectif :

* **Identifier** les matricules dupliqués
* **Conserver le premier** (le plus ancien `id`)
* **Générer un nouveau matricule unique et séquentiel** pour chaque doublon
* Format : `CSMYYMMXXX` (comme `CSM2510002`)

---

## 🛠️ Étapes à suivre :

---

### 1. 👁‍🗨 **Vérifier les doublons existants**

```sql
SELECT matricule, COUNT(*) AS nb
FROM eleves
GROUP BY matricule
HAVING nb > 1;
```

---

### 2. 🧼 **Script SQL pour corriger les doublons**

Voici un script **MySQL pur** (compatible avec MySQL 8+) :

```sql
-- Variables pour le préfixe
SET @prefix = 'CSM';
SET @annee = DATE_FORMAT(NOW(), '%y');  -- ex: '25'
SET @mois = DATE_FORMAT(NOW(), '%m');   -- ex: '10'
SET @global_counter = 0;

-- Crée une table temporaire pour suivre les doublons
CREATE TEMPORARY TABLE temp_doublons AS
SELECT id, matricule,
       ROW_NUMBER() OVER (PARTITION BY matricule ORDER BY id) AS rn
FROM eleves;

-- Met à jour uniquement les doublons (rn > 1)
UPDATE eleves e
JOIN temp_doublons t ON e.id = t.id
SET e.matricule = CONCAT(@prefix, @annee, @mois, LPAD(@global_counter := @global_counter + 1, 3, '0'))
WHERE t.rn > 1;

-- Supprime la table temporaire
DROP TEMPORARY TABLE temp_doublons;
```

---

### 3. 🔐 **Ajouter la contrainte d’unicité**

**IMPORTANT :** Fais cela *après* avoir corrigé tous les doublons :

```sql
ALTER TABLE eleves ADD UNIQUE (matricule);
```

---

### ✅ Résultat :

* Les **doublons** auront été **renumérotés** avec des nouveaux matricules valides
* Tous les matricules sont maintenant **uniques**
* Tu peux désormais ajouter une contrainte `UNIQUE`
* Les futurs matricules seront générés proprement via CodeIgniter (grâce au compteur)

---

✅ Fais d'abord une **sauvegarde** de ta table avant d’exécuter le script :

```sql
CREATE TABLE eleves_backup AS SELECT * FROM eleves;
```
